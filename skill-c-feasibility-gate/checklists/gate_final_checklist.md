# 门控收口清单（阶段 6；任一不过则 status 不得为 success）

## 契约与诚实
- [ ] result.json 含 case_id 与 output_contract 全部原始字段，字段名逐字一致
- [ ] 无虚构的设备、数据、经费、周期或文献
- [ ] status 与实际完成度一致；partial 已写明缺口

## 前提与门
- [ ] 前提台账每条都有三态标记（[来源]/[推断]/[假设:验证方式]）
- [ ] 五道门均有判定且引用了前提编号
- [ ] 假设占比 >50% 时结论未给 go
- [ ] fail 前提未被略过；结论与门判定一致（fail→no-go 或已说明缓解）

## 风险与结论
- [ ] 风险登记覆盖全部 conditional/fail/unknown 前提；缓解措施具体
- [ ] 结论为 go / conditional-go / no-go / indeterminate 之一，且附对应的条件清单/障碍清单/缺口清单
- [ ] 成功判据与终止条件已写明；缺失处标"未指定"并说明影响
- [ ] 参照系（baseline_scan）每行有来源定位；提案差异点已回链风险编号

## 不确定性
- [ ] 假设清单、证据冲突、空白项已进入 result.json 不确定性字段
