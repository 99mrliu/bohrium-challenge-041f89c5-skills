# protocol-first-evidence-review

协议先行的科研选题证据综述 Skill。面向"给定固定研究问题 + 一批文献材料，完成证据整理与选题/创新性评估"的场景。

## 安装与调用

- 安装：将本目录作为 Skill 加载（评测环境安装于 `/skills/weekly-skill`）。无代码依赖、无网络要求；仅使用运行环境自带的 shell 与 PDF 文本提取工具。
- 调用：Agent 读取 SKILL.md 后按六个阶段执行即可，无需额外提示。

## 输入 / 输出

- 输入：`/input/task.md`、`/input/case.json`（含 `case_id`、`output_contract`）、文献材料（PDF/JSON/CSV）。
- 输出：`/app/output/result.json`（含 `case_id` 与契约全部字段、status、sources、uncertainty），以及过程物证（协议、筛选日志、证据矩阵、综合稿）按契约要求一并放入 `/app/output`。

## 方法要点

1. 问题结构化：PICO 式拆解为可检验问题陈述（对象/变量/基线/预期/证伪条件）。
2. 协议冻结：检索式、来源、时间窗、纳排标准在打开全文前冻结，修订强制留痕。
3. 筛选留痕：每条候选记录一行判定+标准编号+理由。
4. 证据矩阵：每格带来源定位（文件+页码/小节/记录号），冲突证据强制入矩阵。
5. 综合与边界：创新点逐条覆盖判定（附检索边界声明），可行性前提逐条标 [来源]/[假设]，结论带条件。

## 适用范围与限制

- 适用：有固定研究问题与文献材料的证据综述、系统筛选、选题与创新性评估。
- 不适用：无研究问题的开放写作；无文献材料的纯观点咨询。
- 已知限制：无联网检索通道时覆盖边界为输入文献集，Skill 会显式声明该边界而不外推。

## 失败处理与自查

异常（空检索、文献过少、证据冲突、解析失败、权限不足、预算将尽）按 SKILL.md 异常处理手册执行；交付前过 `checklists/final_checklist.md`。示例见 `examples/minimal_example.md`（示意输出已标注为示例）。
